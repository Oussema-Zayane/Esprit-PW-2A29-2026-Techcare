## TechCare
Plateforme web intelligente de services écologiques


## Description :
TechCare est une plateforme web qui permet aux utilisateurs d’acheter des produits technologiques et de réparer leurs appareils en un seul endroit.
Elle résoudre le problème des services séparés et peu pratiques en proposant une solution centralisée, intelligente et écologique. 

## Problématique résolue :
 - Difficulté à trouver un réparateur fiable

 - Absence de plateforme spécialisée en réparation technologique

 - Manque de recommandations intelligentes

 - Augmentation des déchets électroniques 

## Solution proposée :
 - Une plateforme web centralisée

 - Recherche intelligente

 - Réservation en ligne

 - Recommandations basées sur l’IA

 - Approche écologique (réduction des déchets électroniques)

## Fonctionnalités principales :
 - Recherche combinée achat / réparation

 - Localisation des points de réparation proches

 - Recommandation du meilleur réparateur via IA

 - Comparaison selon la distance, la qualité et le prix

 - Réservation en ligne simple et rapide

 - Gestion des commandes, paiements, livraison et suivi

## 🚀 Technologies utilisées
 - Frontend : HTML, CSS, JavaScript 

 - Backend : HTML, CSS, JavaScript

 - Base de données : MySQL

 - IA : Python (scikit-learn, TensorFlow) pour les recommandations

 - Versioning : Git & GitHub
