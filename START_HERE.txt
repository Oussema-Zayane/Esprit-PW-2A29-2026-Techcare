PRÉALABLE - Avant de commencer
═════════════════════════════

1. ✅ Installez XAMPP
   URL: https://www.apachefriends.org/

2. ✅ Lancez XAMPP Control Panel
   - Cliquez "Start" sur Apache
   - Cliquez "Start" sur MySQL
   - Attendez que les deux soient verts

3. ✅ Vérifiez que le dossier est à:
   c:\xampp\htdocs\web

🚀 ÉTAPES D'INSTALLATION (À FAIRE DANS CET ORDRE)
═══════════════════════════════════════════════════

ÉTAPE 1: Page d'accueil (Diagnostic automatique)
──────────────────────────────────────────────

URL: http://localhost/web/hello.php

QUE VOIR:
✅ 4 statuts: Base de Données, Table, Données, Système
✅ Un bouton "Configuration" ou "Accéder à l'App"

QUOI FAIRE:
→ Si le système n'est pas prêt, cliquez le bouton "Configuration"
→ Sinon, continuez à l'étape 2


ÉTAPE 2: Configuration de la base de données
─────────────────────────────────────────

URL: http://localhost/web/setup.php

ÉCRAN ATTENDU:
✅ Liste des étapes d'installation
✅ Tous les points doivent devenir VERTS (✅)

QUOI FAIRE:
→ Attendez que tous les points deviennent ✅
→ Boutons: "Retour au site", "Diagnostic", "Rafraîchir"


ÉTAPE 3: Vérifier l'installation
───────────────────────────────

URL: http://localhost/web/diagnostic.php

ÉCRAN ATTENDU:
✅ Connexion à la base de données: OK
✅ Table 'abonnements': EXISTS
✅ Structure de la table avec colonnes (id, nom_client, email, etc)
✅ Nombres d'abonnements: X enregistrements
✅ Exemples de données en tableau

QUOI FAIRE:
→ Vérifiez que tout est ✅
→ Si pas d'enregistrements, c'est normal, on va en ajouter


ÉTAPE 4: Tester tous les composants
──────────────────────────────────

URL: http://localhost/web/test-system.php

ÉCRAN ATTENDU:
8 tests avec résultats ✅ (verts)
  ✅ Connexion DB
  ✅ Table abonnements
  ✅ Colonnes de la table
  ✅ Données de test (ou avertissement normal)
  ✅ Model Abonnement
  ✅ FrontController
  ✅ AdminController
  ✅ Création abonnement

RÉSUMÉ: X Tests, Y Succès, Z Avertissements, 0 Erreurs


ÉTAPE 5: Tester l'application réelle
────────────────────────────────────

URL: http://localhost/web/index.php?page=offres

QUOI FAIRE:
1. Cliquez sur "Souscrire" pour une offre
2. RemplFacez le formulaire:
   - Nom: Votre nom
   - Email: votre@email.com
   - Type: Choisissez mensuel/annuel
3. Cliquez "Confirmer la souscription"
4. Vous devriez voir "Abonnement créé avec succès"
5. Allez à "Mes abonnements" pour voir votre souscription


ÉTAPE 6: Tester la zone admin
─────────────────────────────

URL: http://localhost/web/index.php?admin

ÉCRAN ATTENDU:
Dashboard avec:
  • Nombre total d'abonnements
  • Nombre d'abonnements actifs
  • Total des revenus

QUOI FAIRE:
1. Cliquez sur "Liste des abonnements"
2. Vous devriez voir vos souscriptions
3. Cliquez "Ajouter un abonnement" pour en ajouter un
4. Remplissez le formulaire et confirmez

❓ DÉPANNAGE RAPIDE
═══════════════════

PROBLÈME: "Erreur de connexion à la base de données"
SOLUTION:
  1. Vérifiez que MySQL est lancé dans XAMPP
  2. Allez à setup.php
  3. Consultez logs.php pour les erreurs

PROBLÈME: "Table n'existe pas"
SOLUTION:
  1. Allez à setup.php
  2. Attendez que tous les points deviennent ✅
  3. Vérifiez avec diagnostic.php

PROBLÈME: "Erreur lors de la souscription"
SOLUTION:
  1. Allez à test-system.php
  2. Vérifiez que tous les tests passent
  3. Vérifiez logs.php pour les erreurs
  4. Allez à setup.php pour reconfigurer

PROBLÈME: "Pas de données après souscrire"
SOLUTION:
  1. Soumettez le formulaire avec un email valide
  2. Allez à test-system.php pour vérifier la création
  3. Allez à diagnostic.php pour voir les données

PROBLÈME: "Connexion refused"
SOLUTION:
  1. Vérifiez que XAMPP est lancé (Apache + MySQL)
  2. Vérifiez que le dossier est à c:\xampp\htdocs\web
  3. Essayez http://localhost/xampp pour vérifier l'installation
