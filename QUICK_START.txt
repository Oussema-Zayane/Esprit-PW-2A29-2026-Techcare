🚀 GUIDE RAPIDE D'INSTALLATION TECHCARE

═══════════════════════════════════════════════════════════════

ÉTAPE 1: Préparer l'environnement
─────────────────────────────────

✅ Installez XAMPP: https://www.apachefriends.org/
✅ Lancez XAMPP Control Panel
✅ Cliquez sur "Start" pour Apache et MySQL


ÉTAPE 2: Accédez à la page d'initialisation
─────────────────────────────────────────

URL: http://localhost/web/

Cela vous affichera un écran de bienvenue avec l'état du système.
Si le système n'est pas prêt, il vous redirigera automatiquement vers setup.


ÉTAPE 3 (IMPORTANT): Initialiser la base de données
───────────────────────────────────────────────

URL: http://localhost/web/setup.php

Cette page va:
  • Créer la base de données "techcare"
  • Créer la table "abonnements" avec tous les champs
  • Ajouter les colonnes manquantes
  • Créer les indexes
  • Insérer les données de test

Attendez que tous les points soient ✅ (verts)


ÉTAPE 4: Vérifier l'installation
──────────────────────────────

URL: http://localhost/web/diagnostic.php

Ceci vous montre:
  • L'état de la connexion à la base de données
  • La structure complète de la table
  • Le nombre d'enregistrements
  • Quelques exemples de données

Vérifiez que tout montre ✅


ÉTAPE 5: Tester tous les composants
────────────────────────────────

URL: http://localhost/web/test-system.php

Ceci exécute 8 tests pour vérifier:
  • La connexion à la DB
  • L'existence de la table
  • Toutes les colonnes
  • Les données
  • Les modèles et contrôleurs
  • L'insertion de données


ÉTAPE 6: Utiliser l'application
───────────────────────────────

URL: http://localhost/web/index.php

Vous pouvez maintenant:
  • Consulter les offres disponibles
  • Souscrire à un abonnement
  • Voir vos abonnements
  • Modifier vos abonnements
  • Résilier vos abonnements


ÉTAPE 7 (BONUS): Accéder à l'admin
─────────────────────────────────

URL: http://localhost/web/index.php?admin

Connectez-vous en tant qu'admin pour:
  • Voir le dashboard avec les statistiques
  • Gérer tous les abonnements
  • Ajouter de nouveaux abonnements
  • Modifier les abonnements existants
  • Supprimer les abonnements

FORMULAIRES À TESTER
════════════════════

1. SOUSCRIPTION (Front Office)
   • Allez à: index.php?page=offres
   • Cliquez sur "Souscrire"
   • Remplissez le formulaire:
     - Nom complet
     - Email
     - Type d'abonnement
   • Cliquez "Confirmer la souscription"
   • Vérifiez que l'abonnement apparaît dans "Mes abonnements"

2. AJOUTER UN ABONNEMENT (Back Office Admin)
   • Allez à: index.php?admin&action=ajouter
   • Remplissez le formulaire
   • Cliquez "Ajouter l'abonnement"
   • Vérifiez que ça apparaît dans la liste

═══════════════════════════════════════════════════════════════

EN CAS DE PROBLÈME
═══════════════════

❌ "Table n'existe pas"
   → Allez à setup.php

❌ "Erreur lors de la souscription"
   → Allez à test-system.php pour diagnostiquer
   → Vérifiez que MySQL est lancé

❌ "Pas de données"
   → Allez à setup.php
   → Remplissez le formulaire de souscription

❌ "Erreur de connexion"
   → Vérifiez XAMPP Apache + MySQL sont lancés
   → Vérifiez localhost:3306 répond

❌ "Mot de passe DB incorrect"
   → Modifiez config/database.php
   → Paramètres: $user, $pass

CONFIGURATION FINALE
════════════════════

Si vous changez les paramètres de la base de données:

Fichier: config/database.php

Modifiez:
  $host = 'localhost';      // Serveur MySQL
  $user = 'root';            // Utilisateur MySQL
  $pass = '';                // Mot de passe
  $db = 'techcare';          // Nom de la base
  $charset = 'utf8mb4';      // Charset
